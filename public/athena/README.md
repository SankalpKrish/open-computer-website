# Athena reference assets

Fonts, Voice and Agent SVG artwork, curtain fallback and Bands shader were adapted
from the user-supplied https://athena-research-website.vercel.app/ reference.
Retrieved 2026-10-24. The shader source is in themes/athena/curtain-shader.ts.

Typeface names in the reference: PP Neue Montreal Regular / Medium, FK Roman
Standard Light, and Geist Mono. Asset files are self-hosted with their original
font data. The curtain fallback was converted to WebP for smaller transfer size.

Copy and figures: Athena by OpenComputer, the 15-page PDF supplied for this task.
No live audio or business records are embedded in the illustrative preview.
